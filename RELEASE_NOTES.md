A fix for call sound on phones.

> **Upgrading:** Android needs this APK; the web app and the installed PWA update by themselves once the server runs this version. Nothing changes on Windows.

### 📞 Calls
- **Calls on phones start on the loudspeaker**, voice calls included, instead of the small earpiece at the top of the phone. A connected Bluetooth, wired or USB headset still takes over.
- **Switch between the loudspeaker and the earpiece** during a call from Speaker → Sound output. On the earpiece the screen goes dark against your ear (Android app).
- In the phone browser and the installed web app (Chrome on Android), Sound output now lists the phone's real routes (loudspeaker, earpiece, headset) instead of only "Default".
