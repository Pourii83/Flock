# ADR-0004: اندروید به‌صورت محلی با Gradle و با کلید خود Flock ساخته می‌شود

**وضعیت:** تصمیم گرفته شده ۲۰۲۶-۱۱-۰۳ · پیاده در v1.5.1
**مرتبط:** [[ADR-0000 - The Decision Register]]

## مسئله
APK ها با EAS (سرویس ابری Expo) و کلید امضای Expo ساخته می‌شدند. بیلد باید محلی و بدون Expo باشد.

## تصمیم
- `scripts/build-android.sh`: `expo prebuild` (پوشه‌ی `android/` ساخته می‌شود و commit نمی‌شود) و بعد `gradlew assembleRelease`.
- امضای ریلیز با کلید خود Flock (PKCS12، RSA 4096) از راه `-Pandroid.injected.signing.*`؛ کلید و رمزش فقط پیش
  maintainer در `.private/` است و هیچ‌کدام در git نیست.
- ABI ها `arm64-v8a,armeabi-v7a`. اپ نصبی **هیچ آدرس سرور پیش‌فرضی ندارد**؛ کاربر آدرس سرور را خودش وارد می‌کند.
- مشکل‌های محیط ویندوز، حل‌شده در خود اسکریپت:
  - Gradle (Java) `HTTPS_PROXY` را نمی‌خواند و Maven گوگل بدون پروکسی در دسترس نیست → پروکسی به‌صورت `-Dhttps.proxyHost` داده می‌شود.
  - مسیرهای C++ از ۲۶۰ کاراکتر بیشتر می‌شد → `scripts/android-short-paths.gradle` پوشه‌ی `.cxx` را به یک مسیر کوتاه
    می‌برد و `CMAKE_OBJECT_PATH_MAX=250` می‌گذارد. `subst` جواب نداد: Node و Gradle دو ریشه‌ی متفاوت می‌دیدند.

## نتیجه
- کلید عوض شد: هر کس APK قدیمی (Expo) را دارد، یک بار باید حذف و دوباره نصب کند.
- APK ای که کس دیگری با کلید دیگری بسازد، روی نسخه‌ی رسمی نصب نمی‌شود (امضا فرق دارد)؛ برای تست مشکلی نیست.
