## Gotchas found

- The Electron launch inherits `ELECTRON_RUN_AS_NODE=1` in this environment; strip it from the child env.
- `window.confirm` (used by delete/leave) does fire a Playwright dialog event in Electron; accept it in the test.
- RN-web text inputs stop Escape from bubbling; `SearchBar` got an `onEscape` prop because a document listener
  doesn't see it.
- The message context menu must be opened via the bubble, not the chat-list preview (same text in the DOM).
- `Tooltip`'s old bubble was clamped to the control width; it now uses a fixed 260 px centered container.
