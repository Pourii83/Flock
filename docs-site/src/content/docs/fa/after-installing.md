1. **با حساب ادمین وارد شوید** و **تنظیمات ← تنظیمات برنامه** را باز کنید. آنجا می‌توانید:
   - ثبت‌نام حساب جدید را باز یا بسته کنید
   - ورود مهمان‌ها (افراد بدون حساب) به لینک جلسه را مجاز یا ممنوع کنید
   - بیشترین حجم فایل ارسالی و مدت نگه‌داری فایل‌ها را تعیین کنید
   - مصرف سرور را ببینید: پردازنده، حافظه، دیسک، حجم دیتابیس و فایل‌های فلاک، کاربران، پیام‌ها و تماس‌های فعال

   رمز ادمین را فراموش کرده‌اید؟ نصب‌کننده را با `--admin <نام>` دوباره اجرا کنید (داکر: `docker compose exec server node src/create-admin.js <نام>`).
2. **اپ‌ها را نصب کنید** (اختیاری): بخش [اپ‌ها](/fa/apps/) را ببینید. در اولین اجرا آدرس سرور را می‌پرسند. همان آدرسی را بدهید که در مرورگر باز می‌کنید، مثلاً `https://chat.example.com`.
3. **تماس بین شبکه‌های مختلف را امتحان کنید** (مثلاً وای‌فای و اینترنت موبایل). اگر وصل می‌شود ولی صدا یا تصویر ندارد، [رله‌ی TURN](/fa/calls/) اضافه کنید.
4. **دستورهای سرویس** (روش ۲ و ۳):

   ```bash
   sudo systemctl status flock          # در حال اجراست؟
   sudo systemctl restart flock         # بعد از ویرایش /etc/flock/flock.env
   journalctl -u flock -f               # لاگ زنده
   curl http://127.0.0.1:4000/api/health   # {"ok":true}
   ```
