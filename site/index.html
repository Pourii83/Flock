Try Flock in your browser

Create an account on the demo server, invite a friend and send a few messages. It runs the latest release.

  • Everything resets daily All accounts, messages and files on the demo are deleted every day at 04:30 UTC (08:00 Tehran). Don't keep anything there.
  • Using the Android or Windows app? Download it from the releases page and enter this server address on the sign-in screen:
  • Calls on the demo The demo has no relay server, so calls may not connect on some mobile or office networks. Your own server can add one.
